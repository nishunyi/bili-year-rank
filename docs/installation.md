# 安装与使用

## Windows 完整增强版

适用 Windows 10 / 11 x64。完整包包含客户端本体、运行资源和年度榜，目标电脑无需预先安装哔哩哔哩、Python 或 Node.js。

### 安装包

1. 下载 `bili-year-rank-full-setup-v0.2.0-x64.exe` 并运行。
2. 按向导完成安装，默认安装到当前用户的 `LocalAppData\Programs\BiliYearRank`。
3. 打开桌面的“哔哩哔哩（年度榜增强版）”，在侧栏选择“年度榜”。

### 免安装包

1. 下载 `bili-year-rank-full-portable-v0.2.0-x64.zip`。
2. 解压整个目录到可写位置，双击 `年度榜增强版.exe`。请保留全部附带文件。

增强版使用 `%APPDATA%\bili-year-rank-enhanced` 保存自己的登录态和设置，首次使用从空白状态开始，需要账户的功能请自行登录。安装包不含开发者账户数据。封面、原生客户端在线功能和视频播放需要联网。

### 官方更新

保留官方“检查更新”和更新通知。当前附带引导包 1.17.2、运行资源 1.19.0。官方整包安装器可能覆盖年度榜引导入口；热更新可能改变路由或页面结构，不能保证未来官方版本继续兼容。

请从桌面增强入口或 `年度榜增强版.exe` 启动。启动器会核对引导文件和已验证的资源版本；发现变化时提示下载适配增强包，并允许继续运行客户端。它不会自动降级、覆盖新官方文件或修改更新源。

本次实测官方更新检查完成，但接口没有返回可供此设备安装的新整包，因此尚未验证真实官方升级后的全部功能。待新版本适配后安装对应增强包即可；重新安装旧增强包则会恢复该包附带的旧基础版本。

### 卸载

在 Windows“已安装的应用”中卸载“哔哩哔哩（年度榜增强版）”。原版客户端不受该卸载流程影响，增强版个人数据默认保留。

## 独立静态页面

1. 下载仓库 ZIP 或 Release 中的静态榜单包并解压。
2. 打开 `output/static/index.html`；静态榜单包中直接打开 `index.html`。
3. 选择发布年份，按需设置标题、UP 主、BV 号和最低播放量筛选。
4. 点击播放，在浏览器中打开对应视频网页。

页面内嵌全部榜单数据，不需要 Python、Node.js 或本地服务器。榜单文字数据可离线浏览，封面加载和视频播放需要联网；图片加载失败时显示占位图。

## 从已安装原版创建增强副本（开发方式）

### 环境

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11 |
| 安装工具 | Python 3.10+ |
| 客户端安装目录 | `C:\Program Files\bilibili` |
| 引导包 | 1.17.2，SHA-256 见 `integration/supported_bootstrap.json` |
| 热更新资源 | 1.19.0 |

安装器核对版本和文件哈希，未知构建会停止。仓库不附带官方客户端、ASAR 归档或账户数据，需自行安装对应客户端。

### 安装

1. 将项目放在固定目录；安装后移动目录需要重新安装入口。
2. 退出哔哩哔哩客户端。
3. 双击项目根目录的 `安装增强入口.cmd`。
4. 打开桌面的“哔哩哔哩（年度榜增强版）”。
5. 在侧栏选择“年度榜”。

年度榜与“首页”“精选”同级，在客户端主内容区显示。点击其他侧栏导航即可离开年度榜，按 Esc 返回首页。启动时等待客户端侧栏就绪后显示入口。

安装器将已安装客户端复制到项目的 `client/` 目录，只对副本引导层添加本地模块入口。副本复用原客户端用户数据，原安装目录不作修改。

年度榜运行时只读取 `output/static/` 中的 JSON，不启动 Python 进程，不在客户端中执行搜索采集。

### 恢复

退出增强版后运行 `恢复原版入口.cmd`，恢复副本引导包并移除增强桌面入口；原版桌面入口保留。
